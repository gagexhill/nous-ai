# Contributing

Use [Issues](https://github.com/gagexhill/nous-ai/issues) for bugs and proposals.
Include your browser, operating system, affected commit and reproduction steps.
Please use synthetic media and omit private recordings or personal information.
For vulnerabilities, follow [SECURITY.md](SECURITY.md).

For a code change, branch from the current default branch and open a pull request.
Explain the problem, resulting behavior and validation performed. Keep changes
focused and preserve existing interactions. [Operations](OPERATIONS.md) owns
setup, optional mesh data and the validation commands; [AGENTS.md](AGENTS.md)
records source constraints. Hosted Actions are disabled, so include local results
and distinguish tests you ran from device checks you could not perform.

Contribute source under the repository's [MIT license](LICENSE). Supply only
material you have the right to contribute. Keep optional face assets out of Git
and check their separate licensing before distribution.

Be respectful and constructive. Harassment, threats, doxxing and discriminatory
conduct are unwelcome. Maintainers may remove harmful content or limit access.
Use GitHub's report-content controls for abuse; avoid reposting sensitive content
in a public issue.
